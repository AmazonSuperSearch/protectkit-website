Frequently Asked Questions

Quick answers to common questions about what ProtectKit does, how Free and Premium work, security findings, Windows permissions, privacy, subscriptions, and support.

General questions

What is ProtectKit?

ProtectKit is a Windows security, privacy, investigation, monitoring, system-protection, and maintenance application designed to make important Windows security information and tools easier to inspect, understand, and use.

What version of Windows is ProtectKit designed for?

ProtectKit is designed for Windows 11.

Where should I download ProtectKit?

Use the official ProtectKit listing in the Microsoft Store. Avoid unknown third-party download sites claiming to distribute ProtectKit.

Does ProtectKit replace Windows Security?

No. ProtectKit is designed to complement Windows security technologies by making them easier to inspect, configure, investigate, and understand.

Security questions

Does ProtectKit replace Microsoft Defender?

No. ProtectKit does not replace Microsoft Defender. It can help you inspect Defender status and use supported Defender functions while adding other security, investigation, monitoring, and system-management capabilities.

Does ProtectKit guarantee that my computer is malware-free?

No. No security product can guarantee detection or prevention of every threat. ProtectKit helps you inspect protections, identify conditions that deserve attention, investigate evidence, and make better security decisions.

Can ProtectKit detect every spyware or stalkerware program?

No. ProtectKit can help identify and investigate suspicious indicators and supported forms of activity, but no tool can guarantee detection of every spyware, stalkerware, or malicious program.

Why does ProtectKit look at network connections?

Network activity can provide important security context. ProtectKit can help associate connections with processes and display information such as addresses, ports, protocols, connection states, and other investigation details.

Is an unfamiliar internet connection dangerous?

Not necessarily. Modern applications routinely connect to cloud services, update servers, content networks, analytics systems, and other internet infrastructure. Investigate the responsible process and surrounding evidence before deciding that a connection is malicious.

Understanding findings

Does “Suspicious” mean ProtectKit found malware?

No. Suspicious means available evidence justifies closer investigation. It is not automatic proof that the item is malicious.

What does “Unknown” mean?

Unknown means ProtectKit does not have enough reliable evidence to make a stronger classification. Unknown does not mean safe, and it does not mean malicious.

What does “Inconclusive” mean?

ProtectKit could not reach a dependable conclusion from the information available. Permissions, missing information, conflicting evidence, Windows conditions, network problems, or unavailable external services can contribute to an inconclusive result.

What does “Needs Attention” mean?

A condition deserves review. The reason depends on the feature involved and may include a disabled protection, a configuration issue, incomplete information, or another condition that should be examined.

Can ProtectKit produce a false positive?

Yes. Security analysis can produce false positives and false negatives. ProtectKit is designed to provide context and evidence so users can investigate rather than relying blindly on a single classification.

Need more detail?

See the Understanding ProtectKit Findings guide for a deeper explanation of evidence, confidence, Suspicious, Unknown, Critical, Inconclusive, and Admin Required results.

Administrator permissions

Why does ProtectKit sometimes require administrator permission?

Windows restricts access to security-sensitive settings and system-level operations. Firewall changes, system repair, service operations, security configuration, and other protected functions may require elevation.

Does “Admin Required” mean there is a security problem?

No. It means Windows requires elevated permission for the requested check or operation. It is a permissions state, not a malware classification.

Should I approve every administrator prompt?

No. Read the Windows User Account Control prompt and understand the ProtectKit action you initiated before granting administrator access.

ProtectKit Free and Premium

Is ProtectKit Free really free?

Yes. ProtectKit Free is intended to provide useful supported features without requiring a Premium subscription.

Is the Free version just a trial?

No. ProtectKit Free is not intended to expire simply because a trial period has elapsed.

Why can I see a Premium page while using Free?

Some Premium pages may remain visible so Free users can understand what the feature does. Premium-only controls or operations remain restricted when Premium is required.

What does Premium add?

Premium expands ProtectKit with supported capabilities such as continuous monitoring, real-time alerts, expanded history, advanced investigation, advanced hardening, and additional Premium protection functionality.

What subscription options are available?

ProtectKit Premium is offered with monthly and yearly billing options. Review the current checkout page for current pricing, taxes, billing intervals, and renewal terms.

Are monthly and yearly Premium different security tiers?

No. They are billing intervals for ProtectKit Premium rather than separate Premium feature tiers.

What happens if I cancel Premium?

Cancellation normally prevents a future renewal according to the applicable purchase terms. When Premium entitlement is no longer active, Premium-only functionality may become unavailable and ProtectKit operates according to the supported Free feature set.

If Premium ends, does Microsoft Defender stop protecting my computer?

No. Microsoft Defender and Windows Firewall are Windows security technologies separate from the ProtectKit Premium subscription.

Privacy and internet access

Does ProtectKit perform analysis locally?

Much of ProtectKit's security and system analysis uses information available locally on your Windows computer.

Does ProtectKit ever use the internet?

Yes. Certain optional reputation and investigation lookups, Premium purchase or entitlement functions, subscription management, support, and other online services require internet access.

What might be sent during an online investigation lookup?

Depending on the feature, information required for the requested lookup may include a file hash, IP address, domain name, or another supported identifier.

Does ProtectKit sell personal information?

No. ProtectKit's Privacy Policy states that ProtectKit does not sell personal information.

Do ProtectKit logs contain information about my computer?

They can. Logs and exported reports may contain timestamps, file paths, process information, network information, findings, or actions performed in ProtectKit. Review logs before sharing them.

Maintenance and repair

Can ProtectKit speed up my computer?

ProtectKit provides practical Windows maintenance, cleanup, optimization, repair, and recovery workflows. Whether performance improves depends on what is causing the computer to be slow. No maintenance tool can guarantee a specific performance improvement.

Why can a repair take a long time?

Some underlying Windows servicing, scanning, and repair operations examine or repair large amounts of system information. The time required depends on the operation and the computer.

Should I interrupt a repair that seems slow?

Not simply because it is taking longer than expected. If an active Windows servicing or repair operation says not to interrupt it, allow it to finish unless normal recovery procedures become necessary because Windows itself has failed.

Should I create a restore point?

A restore point can be useful before significant system configuration changes when System Restore is available and appropriate. Important personal data should also be protected with a proper backup strategy because a restore point is not a replacement for a full backup.

Help and support

What should I do if ProtectKit will not open or a feature fails?

Start with the ProtectKit Troubleshooting guide. It covers startup issues, administrator requirements, scans, repairs, network functions, online lookups, Premium access, restarts, and logs.

How do I report a false positive?

Contact ProtectKit Support and include the feature involved, exact finding, file or process information, publisher or signature information when available, and why you believe the item is legitimate.

How do I contact ProtectKit?

Email support@getprotectkit.com or use the ProtectKit Contact and Support pages.

What information should I never email?

Do not send passwords, authentication tokens, recovery codes, private keys, or complete payment-card information. Review screenshots and logs before sending them because they may contain system information.
