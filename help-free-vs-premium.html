ProtectKit Free vs Premium Help

Understand the difference between ProtectKit Free and ProtectKit Premium, why some controls are locked, how Premium access works, and what happens if a subscription ends.

1. ProtectKit has two editions

ProtectKit is available as ProtectKit Free and ProtectKit Premium.

The Free edition is intended to provide genuinely useful Windows security, investigation, privacy, and maintenance capabilities. Premium expands ProtectKit with continuous monitoring and additional advanced functionality.

ProtectKit Free is not intended to be a countdown trial.

You can continue using the supported Free features without upgrading simply because a trial period expired.

ProtectKit Free

Designed for users who want useful manual security and system tools without a subscription.

  • Security posture and dashboard information
  • Supported Microsoft Defender controls
  • Firewall status and supported firewall tools
  • Firewall rule inspection
  • DNS assessment and supported protection options
  • Supported Windows hardening checks
  • Manual system-change verification
  • Snapshot network-connection review
  • Startup and service review
  • Privacy tools
  • Maintenance and repair workflows
  • Basic logs and reports

ProtectKit Premium

Designed for users who want ProtectKit actively watching more areas over time and providing advanced capabilities.

  • Continuous System Change Monitoring
  • Continuous Live Connection Monitoring
  • Real-time alerts
  • Expanded scan and activity history
  • Advanced investigation features
  • Advanced hardening features
  • Additional Premium security and protection functionality

2. What can I do with ProtectKit Free?

ProtectKit Free is intended to let you perform meaningful security reviews and Windows maintenance without requiring payment. You can use supported Free tools to inspect important Windows protections, investigate system information, review startup programs and services, examine network information, use maintenance tools, and review supported logs and reports.

The exact Free feature set can evolve as ProtectKit is updated. The application itself should be treated as the authoritative indication of whether a particular control is currently available in Free or requires Premium.

3. What does ProtectKit Premium add?

Premium is focused primarily on capabilities that go beyond a manual or snapshot review. This includes supported continuous monitoring, real-time alerting, advanced investigation, expanded history, advanced hardening, and other Premium protection capabilities.

This means the difference is not simply “the Free version does nothing and Premium does everything.” The intent is for Free to remain useful while Premium provides deeper and more continuous protection.

4. Why can I see a feature that I cannot use?

ProtectKit may allow Free users to see a Premium page or learn what a Premium capability does even when the active control is restricted to Premium.

This is intentional when implemented that way. It lets you understand what the feature is before deciding whether Premium is useful to you.

A visible page does not necessarily mean every action on that page is included in Free.

If a control requires Premium, ProtectKit should identify that requirement rather than performing the Premium operation for a Free user.

5. Monthly and yearly Premium

ProtectKit Premium is offered with monthly and yearly billing options. Monthly Premium is currently $3.99 per month. Review the current checkout page for the current yearly price.

The Premium feature set is based on having an active qualifying Premium entitlement. The billing interval determines how often the subscription renews, not a separate security tier.

Always review the current checkout page for the price, billing period, taxes, renewal terms, and transaction details that apply to your purchase.

6. How Premium access is recognized

ProtectKit needs to determine whether the current user has a valid Premium entitlement before enabling Premium-only functionality. Internet access may therefore be required for purchase, activation, entitlement validation, renewal, or account-related functions.

If you have purchased Premium but ProtectKit still behaves as though you are using Free, first confirm that the purchase completed successfully and that the computer has working internet access.

If the problem continues, contact ProtectKit Support and describe which Premium feature remains unavailable.

7. How do I cancel Premium?

Subscription management is handled through the account or customer-management process associated with the ProtectKit Premium purchase. Follow the subscription-management option provided with your purchase or the applicable payment provider's customer portal.

Cancellation normally prevents a future renewal. The precise billing and cancellation terms shown by the payment provider for your purchase control.

Cancellation and refunds are different things.

Stopping future renewal does not automatically mean the current paid billing period is refunded. Refund eligibility is governed by the applicable purchase terms, payment-provider process, and applicable law.

8. What happens when Premium access ends?

When a qualifying Premium entitlement is no longer active, Premium-only functionality may become unavailable and ProtectKit should operate according to the Free feature set.

Your Windows computer does not become “unprotected” simply because ProtectKit Premium ends. Windows security technologies such as Microsoft Defender and Windows Firewall are separate Windows protections. ProtectKit is designed to complement them, not replace them.

Any local logs or reports already created remain subject to the normal behavior of those local files and the applicable ProtectKit functionality.

9. Does Premium require an internet connection?

Many ProtectKit analyses use local Windows information. However, Premium entitlement verification and certain online investigation, reputation, purchase, subscription, or account functions require internet connectivity.

If an online-dependent function cannot reach its required service, ProtectKit may be unable to complete that function even though local features continue to work.

10. Premium troubleshooting

If you believe Premium should be active but a Premium feature is unavailable:

  • Confirm that the Premium purchase completed successfully.
  • Confirm that Windows has an active internet connection.
  • Close and reopen ProtectKit if the purchase or entitlement changed while the application was running.
  • Check whether the problem affects one Premium feature or all Premium functionality.
  • Note any message ProtectKit displays about the entitlement or feature.
  • Do not send passwords or complete payment-card information to ProtectKit Support.

If the issue continues, contact ProtectKit Support at support@getprotectkit.com with the feature involved and what ProtectKit displays.

11. Frequently asked questions

Do I have to buy Premium to use ProtectKit?

No. ProtectKit Free is intended to remain useful without a Premium subscription.

Is ProtectKit Free a trial?

No. ProtectKit Free is not intended to expire simply because a trial period has elapsed.

Are there separate monthly and yearly feature sets?

No. Monthly and yearly refer to the billing interval for ProtectKit Premium rather than separate Premium security tiers.

Why does a Premium page appear in Free mode?

Some Premium pages may remain visible so Free users can understand the capability. The Premium-only action itself should remain restricted when Premium is required.

If I cancel Premium, does Microsoft Defender stop working?

No. Microsoft Defender is a Windows security technology. ProtectKit complements Windows security and does not replace Defender.

Does Premium guarantee my PC cannot be infected?

No. No security product can guarantee complete protection or detection of every threat. Premium expands ProtectKit's capabilities but does not create an absolute security guarantee.

Where can I compare the editions before purchasing?

Use the main Free vs Premium page for the current product comparison and purchase information.
