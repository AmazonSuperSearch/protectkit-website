Protection and investigation

Important Windows security tools in one place

ProtectKit helps users verify protections, investigate suspicious activity, reduce attack surface, and respond with clearer information.

S

System Change Monitor

Verify protected system files, security settings, and credential protections while monitoring for important changes.

N

Live Connections

See which processes and services are communicating, investigate remote addresses, and review trust evidence.

F

Firewall Management

Review firewall profiles, inspect rules, apply recommended settings, and control network access.

D

Microsoft Defender

Review Defender status, update protection, run trusted Windows scans, and understand scan results.

H

Windows Hardening

Check important Windows security protections and identify settings that may reduce your attack surface.

I

Startup and Service Investigation

Examine startup entries and services using signatures, publishers, file paths, hashes, and trust evidence.

DNS

DNS Protection

Review DNS configuration and apply supported secure DNS profiles across the Windows system.

L

What was found

A program configured to start with Windows could not be fully verified.

Why it matters

Startup programs run automatically and may remain active without the user opening them.

Available evidence

ProtectKit can display the executable path, publisher, signature status, source, hash, and trust assessment.

Recommended action

Review the program, verify that you recognize it, and investigate further before removing or disabling it.
