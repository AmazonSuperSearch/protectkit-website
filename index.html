Frequently asked questions

What users should know before installing

Is ProtectKit an antivirus?

ProtectKit is not marketed as a replacement antivirus. It works with Windows security technologies, including Microsoft Defender and Windows Firewall, while adding assessment, investigation, hardening, monitoring, logging, and guided maintenance capabilities.

Does ProtectKit replace Microsoft Defender?

No. ProtectKit can help you review and use Microsoft Defender features, but Defender remains Microsoft's built-in anti-malware platform.

Why does ProtectKit need administrator permission for some actions?

Windows restricts access to many security, firewall, system repair, service, and configuration operations. ProtectKit only receives those privileges when Windows grants them.

What does the Free edition include?

The Free edition includes the dashboard, manual security assessments, Defender and firewall tools, DNS protection, selected hardening, manual System Change verification, connection snapshots, startup and service review, privacy assessment, maintenance tools, and basic logs and reports.

What does Premium add?

Premium adds continuous monitoring, real-time alerts, advanced investigation, advanced hardening, unlimited scan history, and deeper security and trust analysis.

Does ProtectKit upload everything on my computer?

ProtectKit's system inspection and logging are designed around local Windows information. Optional online investigation features may send the minimum information needed for a requested lookup, such as a file hash or remote IP address, to the applicable third-party service.

Can ProtectKit guarantee that my PC is malware-free?

No security product can guarantee that. ProtectKit is designed to improve visibility, configuration, investigation, monitoring, and response while complementing established Windows protections.

Where can I report a bug or suggest a feature?

Email support@getprotectkit.com. Include the feature you were using, what you expected to happen, what happened instead, and any non-sensitive screenshots or ProtectKit logs that help explain the issue.
